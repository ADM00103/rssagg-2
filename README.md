# rssagg-2
RSSagg 2 (ОБНОВЛЕННАЯ ВЕРСИЯ) — IT News Aggregator, PHP-агрегатор IT-новостей с RSS-парсингом, извлечением полного текста, локальным кэшем картинок, сохранением в `txt`, вторичным `index.json`, автоматической группировкой новостей и отдельной RSS-лентой. А также автоматический все чистится для экономии места на диске, добавлено ограничение вывода RSS ленты в 50 постов!
