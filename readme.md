# IT News Aggregator - RSSagg 2

PHP-агрегатор IT-новостей с RSS-парсингом, извлечением полного текста, очисткой мусора из статей, локальным кэшем изображений, хранением новостей в `index.json` и отдельной RSS-лентой.

## Возможности

- Парсинг RSS-лент.
- Извлечение текста со страницы новости.
- Очистка мусора вроде JavaScript, рекламных вставок, скриптов и служебных фрагментов.
- Ограничение обработки до 50 новостей за один запуск.
- Локальный кэш новостей и изображений.
- Автообновление без cron.
- Поддержка cron для серверного обновления.
- Светлая и тёмная тема.
- Вывод новостей карточками.

## Требования

- **PHP 8.3**
- Расширения:
  - `curl`
  - `dom`
  - `SimpleXML`
  - `xml`
  - `mbstring`
- Доступ на запись в папки:
  - `cache/txt`
  - `cache/img`
  - `data`
  - `logs`

> Важно: проект рассчитан на PHP 8.3. На старых версиях PHP возможны ошибки 500 и проблемы с обработкой RSS и DOM.

## Установка

### 1. Залей файлы на хостинг

Скопируй проект в папку сайта, например:

```text
/public_html/news
```

### 2. Создай папки

Если папки не создались автоматически, создай вручную:

```text
cache/txt
cache/img
data
logs
```

### 3. Проверь права доступа

Папки `cache`, `data` и `logs` должны быть доступны для записи веб-сервером.

### 4. Настрой `config.php`

Укажи:
- `site_url` — адрес сайта;
- `cron_token` — секретный токен для cron;
- `max_items_per_refresh` — лимит новостей за один запуск;
- список RSS-источников.

### 5. Первичное обновление

Открой в браузере:

```text
https://w99522bk.beget.tech/refresh.php?token=YOUR_SECRET_TOKEN
```

После этого создадутся:
- `data/index.json`;
- `data/last_update.txt`;
- кэш новостей в `cache/txt`;
- кэш изображений в `cache/img`.

## Как работает автообновление

Есть два режима:

### Режим с cron

Сервер сам по расписанию запускает:
- `refresh.php` — обновление новостей;
- `cleanup.php` — очистку старых файлов.

### Режим без cron

Если cron не используется, сайт сам обновляется при открытии страницы.  
Для этого в `index.php` и `rss.php` вызывается `autoMaintenance()`.

> Это не фоновый демон. Обновление запускается при посещении сайта, если прошло достаточно времени с последнего обновления.

## Настройка cron

Если хостинг позволяет cron, добавь задания:

```cron
*/15 * * * * /usr/bin/php8.3 /home/USERNAME/public_html/news/refresh.php >/dev/null 2>&1
10 0 * * * /usr/bin/php8.3 /home/USERNAME/public_html/news/cleanup.php >/dev/null 2>&1
```

### Что делают задания

- `refresh.php` — обновляет новости.
- `cleanup.php` — удаляет старые кэши и устаревшие данные.

### Если используется внешний cron-сервис

Вызывай такие URL:

```text
https://w99522bk.beget.tech/refresh.php?token=YOUR_SECRET_TOKEN
https://w99522bk.beget.tech/cleanup.php?token=YOUR_SECRET_TOKEN
```

> На слабом или защищённом хостинге внешний cron может получать `403 Forbidden`, `connection failed` или `504 Gateway Time-out`. В таком случае лучше использовать встроенное автообновление без cron.

## Ограничение нагрузки

Проект ограничивает обработку до **50 новостей за один запуск**.

Это снижает:
- вероятность `504 Gateway Time-out`;
- нагрузку на слабый хостинг;
- время ответа при ручном запуске обновления.

Если нужно, лимит можно изменить в `config.php`:

```php
'max_items_per_refresh' => 50,
```

## Очистка текста

При парсинге текст автоматически очищается от:
- `<script>`;
- `<style>`;
- `<noscript>`;
- `<iframe>`;
- HTML-комментариев;
- рекламного и JavaScript-мусора;
- вставок вроде `window.yaContextCb...`;
- вставок вроде `zen.yandex.ru/widget-loader`.

В тексте остаётся только нормальный контент статьи.

## RSS

RSS-лента отдаёт:
- `title`;
- `link`;
- `pubDate`;
- `description` с коротким анонсом;
- `content:encoded` с полным текстом;
- `enclosure` для изображения, если оно есть.

Открыть RSS можно так:

```text
https://w99522bk.beget.tech/rss.php
```

или через rewrite:

```text
https://w99522bk.beget.tech/rss.xml
https://w99522bk.beget.tech/feed.xml
```

## Возможные проблемы

### Ошибка 500

Проверь:
- что используется **PHP 8.3**;
- что включены расширения `curl`, `dom`, `SimpleXML`, `xml`, `mbstring`;
- что папки `cache`, `data`, `logs` доступны на запись.

### Ошибка 504 Gateway Time-out

Причины:
- слишком много новостей за один запуск;
- слабый хостинг;
- долгий ответ от внешнего RSS;
- слишком тяжёлый парсинг страницы.

Что сделать:
- оставить лимит `50`;
- уменьшить его до `20–30`, если нужно;
- сократить число источников;
- использовать автообновление без cron.

### Кривой текст или мусор в описании

Если в тексте виден JavaScript или рекламные куски, проверь:
- что используется актуальный `lib.php`;
- что парсинг идёт через `stripNoiseHtml()` и `extractArticleText()`;
- что старый кэш очищен.

## Быстрый запуск

1. Залить файлы.
2. Создать папки `cache/txt`, `cache/img`, `data`, `logs`.
3. Указать `site_url`, `cron_token`, `max_items_per_refresh`.
4. Запустить `refresh.php`.
5. Открыть сайт.
6. При необходимости подключить cron.
